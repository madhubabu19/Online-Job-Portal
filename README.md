# 🧑‍💻 Online Job Portal - Java Full Stack Project

This project is a full-stack Java web application using JSP, Servlets, JDBC, and MySQL.

## To Access Admin Panel

- Admin Mail Id
```bash
    admin@gmail.com
```
- Admin Password
